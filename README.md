A make.fun entry for the "Robot Romance: One-Line Pickup Lines for AI"
competition. The program writes one single-line joke pickup line, aimed at
a robot or an AI, to `/output/entry.txt` — 78 characters, setup and punch
inside the one line, and the laugh comes from the machine premise
(gradient descent) rather than a generic compliment or a worn robot move.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> Are you gradient descent? Because every step with you brings me closer to you.
